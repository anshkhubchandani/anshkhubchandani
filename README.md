# Hi, I'm Anshul Khubchandani 👋

M.Sc. Bioinformatics student at Friedrich Schiller University Jena, working at the intersection of **genomics, machine learning and mass spectrometry**.

- **Genomics:** long-read sequencing of clinical *Enterobacter cloacae* complex isolates: species classification, antimicrobial resistance, virulence and prophage analysis (281 isolates vs. 15,080 public genomes)
- **Mass spectrometry:** machine-learning retention time prediction to improve small-molecule identification with SIRIUS / CSI:FingerID
- **Data science:** statistics, pattern recognition and data visualization

**Looking for:** a dry-lab role in data science or computational biology (pharma / biotech).
